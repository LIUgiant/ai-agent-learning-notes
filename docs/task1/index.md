# Task 1 · 上下文工程与 Memory / RAG

**课程范围**：第 2、3 章。**作业截止**：09 月 20 日 03:00（按任务原文记录）。

目标：理解上下文窗口与组织方式、短期上下文与长期记忆的区别、RAG 在 Agent 中的作用；跑通后修改 prompt、context 或检索参数并比较。

## 这次怎样学

1. [概念与项目联系](concepts.md)：先画清信息在哪里。
2. [上下文实验](context.md)：比较完整内容、截断与摘要。
3. [长期记忆实验](memory.md)：提取、保存、换会话重载、纠正偏好。
4. [检索与 RAG](rag.md)：调 top-k、观察漏召回，再把文档交给模型。
5. [运行记录与复现](evidence.md)：查看本次实测结果、请求和边界。

## 与书中实验的对应关系

| 本次工作 | 复用课程代码 | 完成范围 |
| --- | --- | --- |
| 上下文对照 | 2-10 `ContextCompressor` | 固定教学材料上的压缩与回答；不是原版 128K 研究任务全套复现 |
| 长期记忆 | 3-2 `NotesMemoryManager` | 显式偏好提取、持久化和纠正；不是四模式 / 三层评测全集 |
