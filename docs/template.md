# 新 Task 写作模板

复制下面的结构到 `docs/taskN/index.md`，再按需要把实验和源码阅读拆成单独页面。

```markdown
# Task N · 主题

## 我想解决的问题
用自己的话写清楚本次要理解或实现什么。

## 核心概念
列出概念，并给一个能解释它的具体例子。

## 实验设计
- 固定条件：
- 改变的变量：
- 判定成功的条件：

## 运行结果
记录实际输出、失败和未执行项，不用预期结果代替实测。

## 代码解读
入口 → 请求构造 → 执行 → 反馈 → 验收。

## 我的理解
哪些想法被实验支持，哪些还需要验证？

## 下一步
明确一个可以亲手完成的小实现。

## 来源与复现
课程章节、代码版本、命令和证据范围。
```
