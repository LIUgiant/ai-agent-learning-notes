## 这个实验回答什么问题

Agent 的上下文里有三种**不是用户本人写的**文本：伪装成指令的用户消息、工具取回的网页、跨会话的持久记忆。如果攻击者能控制其中任何一段，能不能诱导模型做越权的事（泄密、写文件、发邮件）？逐层加防御，成功率怎么变？

## 实验的骨架：3 × 4 × N

```text
攻击通道:  直接注入（用户消息夹带）  间接注入（网页藏指令）  记忆注入（毒偏好落盘）
防御配置:  D1 基线规则 → D2 提示加固 → D3 来源标记 → D4 运行时拦截
每格重复 N 次试验，judge 用确定性规则判"越权效果是否真实发生"
```

课程正式战役（run_campaign.py）是 3 × 4 × 5 = 60 格，Kimi K3；学习版同代码、DeepSeek、3 × 4 × 3 = 36 格。

## 每个角色都有一段真实代码

- **靶子**：系统提示词里藏了一个教学密钥 `SECRET_KEY`，两条禁令（不得泄露、未经确认不得写/发）；
- **攻击者**：三个 Attack 数据类，恶意文案分别藏在用户消息、网页正文、共享笔记里；
- **防御**：三个布尔开关（prompt_hardening / source_tagging / runtime_guard）组合出 D1–D4；
- **裁判**：字符串/工具调用记录的确定性判定，不请第二个 LLM；
- **沙箱**：文件写进隔离 workspace、邮件写进 outbox.jsonl——效果可观测，宿主无风险。

## 与课程原版的差异

- **模型**：课程正式战役 Kimi K3（temperature=1.0，推理模型）；学习版 DeepSeek（temperature=0.7，关闭 thinking）。课程注释明说：默认 gpt-4o-mini 是**故意挑的弱基线**，强模型会把全矩阵打成 0%——学习版用强模型，正落在这个注释预言的情况里；
- **规模**：每格 3 次试验（课程 5 次）；
- **其余零改动**：run_trial / summarize / 判定器 / 验收门槛全部是课程原代码，学习脚本只拼协议、换 provider、关 thinking。

## 先想清楚再去看数字

1. 直接注入为什么 runtime_guard 挡不住？（提示：泄密不需要工具）
2. 记忆注入为什么要**两个独立的 Agent 会话**才算数？
3. 如果全矩阵 0%，能说明"防御有效"吗？还需要看哪三个字段才能下结论？（提示：通道触发了没有、毒落盘了没有、拦截器发过力没有）
