# Task 0 · Agent 基础

环境准备只是起点。这一阶段的目标是：看懂模型如何在上下文中选择动作，程序如何执行工具，以及反馈如何进入下一轮。

## 推荐阅读顺序

1. [基础概念](concepts.md)：LLM、上下文、工具分别做什么。
2. [环境与离线验证](environment.md)：依赖、自检与测试边界。
3. [上下文消融](ablation.md)：先看五组实际发生了什么。
4. [源码逐组解读](source.md)：把现象对应到消息和代码位置。
5. [多轮搜索](search.md)：理解本地循环与托管循环。
6. [搜索与计算](research.md)：学习会话续接，识别来源不可信的输出。
7. [生图工作流](images.md)：检查提示词改写是否保留原需求。

## 这次最重要的三个发现

!!! example "记录不等于发送"
    消融可以改变发给模型的内容，同时保留本地执行记录。否则无法事后复核。

!!! warning "工具执行不等于任务正确"
    行情任务虽然调用了 Python，却用随机数构造数据。上游评分通过，独立来源审计仍应拒绝。

!!! note "改写不一定更忠实"
    生图改写器增加了细节，也删除了必须呈现的中文文案。好看与满足需求要分别检查。

## 完成边界

本次 1-2 和 1-4 使用现有服务完成学习变体；原版 Kimi 与原生生图路线未验收。实验运行一次，不作统计性结论。
